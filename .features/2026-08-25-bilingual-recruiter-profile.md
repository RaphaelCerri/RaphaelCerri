## O que mudou

O perfil ganhou uma versão completa em português com seletor de idioma. A versão inglesa principal foi simplificada, removendo as seções de método e evidência detalhada que já pertencem aos repositórios individuais.

## Por que

O GitHub não seleciona automaticamente um README pela linguagem do navegador. Inglês como página principal atende recrutadores internacionais, enquanto a tradução explícita preserva acesso para leitores brasileiros sem duplicar detalhes técnicos desnecessários no perfil.

## Como usar

Abra `README.md` para inglês ou `README.pt-BR.md` para português. Os links no topo permitem alternar entre as duas versões.

## Notas

O cabeçalho SVG animado e não clicável foi mantido nas duas versões.
