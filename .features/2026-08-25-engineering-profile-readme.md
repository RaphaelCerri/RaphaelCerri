## O que mudou

O perfil público passou a apresentar posicionamento de AI Engineer e AI Solutions Architect,
projetos selecionados, métricas reproduzíveis, princípios de engenharia e limites de autoria com
assistência de IA. Um cabeçalho SVG próprio adiciona identidade visual e animação leve.

## Por que

O conjunto de repositórios já continha evidência técnica forte, mas o perfil não oferecia uma
narrativa única para recrutadores. A página conecta RAG avaliado, MCP seguro, governança de agentes
e entrega de software sem depender de widgets externos instáveis.

## Como usar

O GitHub renderiza automaticamente `README.md` no perfil porque o repositório possui o mesmo nome
do usuário. Os projetos e métricas possuem links diretos para suas evidências.

## Notas

O SVG respeita `prefers-reduced-motion`. Cards de estatísticas de terceiros foram evitados para
reduzir dependências, falhas de carregamento e claims sem relevância técnica.
